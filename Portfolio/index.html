Optionally encrypt this browser's portfolio data, cached prices, Apps Script URL, and recovery snapshots. The passphrase is never stored. Your Google Sheet and downloaded JSON backups remain separate and are not encrypted by this setting.

Privacy

Your data stays with the backend you choose:

  1. This browser's local storage on the device you're using right now.
  2. Legacy mode uses the Google Sheet you created and own. NAS mode uses the private same-origin Supabase gateway configured in the Backend card.

What the public site stores: nothing. This static page has no central portfolio database. It calls the backend selected in Settings, legacy Apps Script or your private NAS gateway, and rejects arbitrary backend hosts.

What you are responsible for: securing the Apps Script URL or NAS account, keeping TOTP and device passphrases private, and protecting the device this app runs on.

To delete your data: use Reset local data for the legacy browser cache. In NAS mode, use the NAS recovery and administration procedure for server records, then sign out and clear this device's protected cache.
